# Ujjval Mishra | Portfolio

My personal portfolio website, built with HTML, CSS and JavaScript with help from Claude. It works on desktop and Android, and it is a single `index.html` file with no build step.

## Live site

https://ujjval-9.github.io/Portfolio/

## Features

- Responsive dark design for PC and phone
- Fixed top bar with a three-line menu, a scroll progress line and section highlighting
- Typing intro line under my name
- Headings whose letters grow near the cursor or finger
- Skill cards that show my level, and education cards that show my year or score, on hover or tap
- Contact cards with copy buttons for email and phone
- Sections that fade in as you scroll, and a back to top button

## Sections

- About
- Contact
- Skills
- Projects
- Education
- Clubs

## Built with

- HTML
- CSS
- JavaScript

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
